Rowan datapoints

This is the initial visible contract for the application.

  • Book: title, author, series, format, ISBN, cover, source
  • Library item: status, owned, shelf, rating, tags, added date
  • Progress: current page, total pages, percent, started, finished
  • Session: date, pages read, minutes, note
  • Series: name, order, books, completion state
  • Queue: position, reason, priority, target date
  • Goal: target, period, progress, streak
  • Account: identity, preferences, export, backup, deletion
